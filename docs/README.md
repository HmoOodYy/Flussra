# Flussra Documentation

This directory contains the project's engineering documentation.

## Structure

- `architecture/` — active architecture contracts, master plans, execution plans, product gaps, and deferred-work registers.
- `future/` — explicitly deferred designs that are not active implementation work.
- `evidence/` — acceptance, validation, and traceability evidence.
- `development/` — developer setup and operational documentation.
- `archive/` — completed, superseded, or historical design and implementation documents.

## Authority

Documents under `archive/` are retained for historical context only and must not be treated as current implementation authority.

When documents disagree, follow the status and authority statements in the active documents under `architecture/`.
